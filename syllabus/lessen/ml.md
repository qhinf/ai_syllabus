# Machine Learning

## Leerdoelen

* Het verschil tussen supervised, unsupervised en reinforcement learning kunnen uitleggen.

* Bovenstaande zelf ervaren via interactieve classificatie-opdrachten (bijv. Teachable Machine)

* Basisinzicht ontwikkelen in bias en hoe dit kan ontstaan in Machine Learning.

## Tijdens de les

De les duurt iets langer, omdat we elkaar aan de hand van verschillende spelletjes beter gaan leren kennen. Daarna gaan we aan de slag met machine learning. Wat is machine learning, wat maakt een machine slim en hoe werkt het eigenlijk? We bespreken de verschillende manieren waarop machines kunnen leren, waaronder supervised learning en unsupervised learning. Ook behandelen we het belang van data en het verschil tussen train data en test data. Daarnaast kijken we naar reinforcement learning en hoe dit werkt. Tot slot bespreken we de mogelijke eindopdrachten (techniek of innovatie) en kijken we naar wat deze opdrachten precies inhouden.
